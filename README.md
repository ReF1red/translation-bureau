# Бюро переводов

Программа для работы с клиентами и заказами на перевод.
В JavaFX доступны таблицы клиентов и заказов, описание выбранного заказа и статистика.
Клиентов можно добавлять, изменять и удалять через формы.
Консольная версия также поддерживает CRUD, поиск, фильтрацию, сортировку и экспорт в Excel.

## Запуск

Для запуска необходимы JDK 21 и PostgreSQL.

1. Запустить сервер PostgreSQL.
2. При первой установке создать базу. В консоли `psql`, открытой из папки проекта, выполнить:

   ```sql
   CREATE DATABASE translation_bureau;
   \connect translation_bureau
   \i sql/schema.sql
   \i sql/data.sql
   ```

3. При первой настройке скопировать `src/main/resources/database.properties.example` в `src/main/resources/database.properties`. Указать адрес, порт, имя базы, пользователя и пароль.
4. Открыть папку проекта в IDE как Maven-проект, выбрать JDK 21 и загрузить зависимости из `pom.xml`.
5. Запустить `bureau.fx.FxMain` или выполнить `mvn javafx:run`. Для консольной версии запустить `bureau.Main`.
