# Бюро переводов

Консольная программа для работы с клиентами и заказами на перевод.
Работают добавление, список, просмотр по ID, изменение и удаление клиентов и заказов.
Статус заказа меняется отдельным пунктом в меню заказов.
Есть поиск по названию и описанию, фильтры по статусу и клиенту, сортировка по сроку и стоимости.
Пункт 5 показывает статистику, пункт 6 сохраняет клиентов и заказы в Excel в папку `exports`.

## Запуск

НАДО СДЕЛАТЬ БД

1.  `CREATE DATABASE translation_bureau;`.
2. `\connect translation_bureau`.
3. `\i sql/schema.sql`, затем `\i sql/data.sql`.
4. ctrl c `src/main/resources/database.properties.example` ctrl v `src/main/resources/database.properties` и заполнить( а то оно в гитигноре чтоб не мусорить да и в принципе так правильно мне кажется)
